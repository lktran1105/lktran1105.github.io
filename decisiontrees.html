DECISION TREES

Overview

1. What Is a Decision Tree?

A decision tree (DT) is a supervised machine learning model that predicts an outcome by asking a sequence of simple questions about the features. It is drawn as a tree. Each internal node tests one feature (for example, "is flipper length < 200 mm?"), each branch is one answer to that test, and each leaf gives a final prediction. To classify a new observation, we start at the root, follow the answers down the tree, and read the prediction at the leaf we reach.

The tree is learned from labeled training data. At each node, the algorithm looks for the feature and threshold that best separates the classes, splits the data accordingly, and repeats on each resulting subset until a stopping rule is met (for example, the subset is pure, or the tree reaches a maximum depth).

2. What Are Decision Trees Used For?

Decision trees can be used for classification (predicting a category, such as penguin species) and regression (predicting a number, such as body mass). They handle both numeric and categorical features, need little data preparation (no scaling is required), and are easy to interpret because the path to any prediction can be read as a series of if/then rules. Typical applications include medical diagnosis, credit risk scoring, customer churn prediction, and exploratory analysis of which features matter most. Their main weakness is that a deep tree can memorize the training data (overfit), so tree size usually has to be limited or pruned.

3. Measuring the Goodness of a Split: Gini, Entropy, and Information Gain

To choose a split, the algorithm needs a number that says how "mixed" the classes are in a set of observations. A node containing only one class is pure, and the goal is to make the child nodes purer than their parent. Two common impurity measures are used, where pi is the proportion of observations in the node that belong to class i:

  • Entropy = −Σ pi log2(pi). It measures disorder in bits. It is 0 for a pure node and reaches its maximum (1 bit for two classes) when the classes are evenly mixed.
  • Gini impurity = 1 − Σ pi2. It is the probability that a randomly chosen observation would be misclassified if labeled at random according to the class proportions in the node. It is 0 for a pure node and 0.5 at its maximum for two classes. It is cheaper to compute because it needs no logarithm.

Information Gain is how much a split reduces impurity: the impurity of the parent node minus the weighted average impurity of the children, where each child is weighted by the fraction of observations it receives.

Information Gain = Impurity(parent) − Σ (nchild / nparent) × Impurity(child)

Impurity is used because we cannot judge a split by looking at accuracy alone: a split can leave the majority class unchanged in both children while still making the groups much purer. Information gain turns "how much cleaner did this split make the data?" into a single number, so every candidate split can be scored and compared. The tree algorithm greedily picks the split with the highest gain at each node. (When Gini is used in place of entropy, the same formula is applied and is often called Gini gain.) The two measures usually pick the same or very similar splits.

Small example

Suppose a node contains 10 penguins: 5 Adélie and 5 Gentoo. This is a made-up example for illustration. We compare two candidate splits using entropy.

Parent node: p(Adélie) = p(Gentoo) = 0.5, so

Entropy = −(0.5 log2 0.5 + 0.5 log2 0.5) = 1.000

Split A: flipper length < 200 mm. The left child has 5 penguins (4 Adélie, 1 Gentoo) and the right child has 5 penguins (1 Adélie, 4 Gentoo).

Entropy of each child = −(0.8 log2 0.8 + 0.2 log2 0.2) = 0.722
Weighted entropy = (5/10)(0.722) + (5/10)(0.722) = 0.722
Information Gain = 1.000 − 0.722 = 0.278

Split B: sex = male. The left child has 5 penguins (3 Adélie, 2 Gentoo) and the right child has 5 penguins (2 Adélie, 3 Gentoo).

Entropy of each child = −(0.6 log2 0.6 + 0.4 log2 0.4) = 0.971
Weighted entropy = (5/10)(0.971) + (5/10)(0.971) = 0.971
Information Gain = 1.000 − 0.971 = 0.029

Split A has a much higher information gain (0.278 vs. 0.029), so the algorithm would choose it: it leaves the children mostly one species, while Split B leaves them nearly as mixed as the parent. Using Gini gives the same ranking. The parent has Gini = 0.5, and the children of Split A have Gini = 1 − (0.82 + 0.22) = 0.32, for a gain of 0.18. The children of Split B have Gini = 1 − (0.62 + 0.42) = 0.48, for a gain of only 0.02.

4. Why Can an Infinite Number of Trees Be Built?

For the same dataset and the same task, there are infinitely many different trees, for several reasons:

  • Continuous features have unlimited thresholds. A split such as "flipper length < t" can use any real number t, and there are infinitely many values between any two observed measurements.
  • Features can be reused. The same feature can be tested again further down a branch with a different threshold, and features can be tested in any order, so the same data can be organized in many different ways.
  • Depth is not fixed. A tree can keep growing, adding more splits (including redundant ones) as long as nodes can be divided, so there is no largest tree.

Many of these trees make identical predictions on the training data, but they are still different trees, and they can behave very differently on new data. Because the number of possible trees is so large, algorithms do not search all of them for the best one. They build a single tree greedily, choosing the best split at each node using a measure such as information gain. Stopping rules and pruning then keep the tree from growing too large and overfitting.

Data Preparation for Decision Trees

1. Data Requirements for Supervised Learning

A decision tree is a supervised method, so it can only learn from labeled data: every observation must come with the correct answer (the class label) the tree is trying to predict. At each node the algorithm tries candidate splits and scores them by how much purer the resulting groups are, and purity can only be measured if the true class of each example is known. Unlabeled observations cannot be used to build or to evaluate a supervised model, because there is nothing to compare predictions against.

Decision trees need relatively little preparation. Unlike distance-based methods, they do not require the features to be scaled, because each split is just a threshold on one feature. The scikit-learn implementation we use does require numeric features and no missing values.

2. Preparing the Penguin Data

For decision trees we use the same Palmer Penguins size measurements as for Naive Bayes, where each row is one individual penguin. The label is the penguin's species (Adélie, Chinstrap, or Gentoo), and the features are four physical measurements: culmen (bill) length, culmen depth, flipper length, and body mass. Species is a known, recorded label for every penguin, which makes this dataset suitable for supervised learning. The goal is to predict species from the measurements alone.

The raw file contains 344 penguins. The 10 rows with missing values were removed, leaving 334 labeled observations. A sample of the cleaned data is shown below.

3. Creating the Training and Testing Sets

To find out how well a tree works on penguins it has not seen, the 334 labeled penguins were randomly split into two parts, using scikit-learn's train_test_split with test_size=0.3 and random_state=42 (a fixed seed so the same split can be reproduced): a Training Set of 233 penguins (about 70%) used to build the trees, and a Testing Set of 101 penguins (about 30%) held back to measure accuracy. For the Testing Set, the tree is given only the measurements, makes a prediction, and the prediction is compared with the true species label.

The two sets must be disjoint, meaning no penguin appears in both. A decision tree can keep splitting until it memorizes its training data, so if the test penguins were also in the training data, the tree could look very accurate just by remembering them, and the accuracy would say little about new penguins. Keeping the sets separate makes the test accuracy an honest estimate of how the tree will generalize. The split is the same one used for the Naive Bayes models, so the methods can be compared on the same test penguins.

Results

Three decision trees were trained on the 233-penguin Training Set (using scikit-learn's DecisionTreeClassifier) to predict species (Adélie, Chinstrap, or Gentoo) from culmen length, culmen depth, flipper length, and body mass. In each node, value lists the number of Adélie, Chinstrap, and Gentoo penguins that reach it, and the node's color shows its majority species (orange = Adélie, green = Chinstrap, purple = Gentoo), with darker colors meaning purer nodes.

All three trees used random_state=42 and min_samples_leaf=5, which requires every leaf to contain at least 5 training penguins so that the tree does not split off tiny, unreliable groups. They differ in the splitting criterion (Gini or entropy) and in whether the depth is limited: Trees 1 and 2 have max_depth=3, and Tree 3 has no maximum depth. After training, each tree was evaluated on the 101-penguin Testing Set it had never seen.

I. Tree 1: Gini, max_depth = 3

The Gini tree starts at the root with the split flipper length ≤ 206.5 mm. The root has Gini impurity 0.644 (97 Adélie, 50 Chinstrap, 86 Gentoo). The split sends 142 penguins left (Gini 0.447) and 91 right (Gini 0.125). The weighted impurity after the split is 0.322, so the Gini gain is 0.644 − 0.322 = 0.322, the largest of any split the algorithm considered at the root.

  • Gentoo: the right branch is almost entirely Gentoo. One more split on culmen depth (≤ 17.55 mm) produces a pure leaf of 85 Gentoo (Gini 0).
  • Adélie vs. Chinstrap: the left branch separates these two species using culmen length and body mass. It finds a pure leaf of 87 Adélie (culmen length ≤ 42.35 mm) and a pure leaf of 38 Chinstrap (culmen length > 43.35 mm and body mass ≤ 4100 g).
  • Impure leaves: three leaves are still mixed: [4 Adélie, 3 Chinstrap], [4, 5, 1], and [2, 4, 0] penguins. The tree was limited to a depth of 3, so it stopped splitting here, and these are where it makes its mistakes.

Counting the penguins that fall in a leaf of a different species than the leaf's majority, the tree misclassifies 10 of the 233 training penguins, a training accuracy of about 95.7%.

II. Tree 2: Entropy, max_depth = 3

The entropy tree picks the same root split (flipper length ≤ 206.5 mm). Here the root has entropy 1.534 and the weighted entropy of the two children is 0.749, so the Information Gain is 1.534 − 0.749 = 0.785. The numbers differ from the Gini tree because entropy and Gini are on different scales, but both criteria agreed on the best first split, and the right branch is identical (a pure Gentoo leaf of 85, and the same [2, 4, 0] leaf).

The trees differ on the left branch. The entropy tree splits culmen length at 42.35 mm first, which immediately isolates the same pure group of 87 Adélie. The remaining 55 penguins ([8, 46, 1]) are then split on body mass into a nearly pure Chinstrap leaf (42 penguins, one Adélie) and a mixed leaf of 13 penguins ([7, 5, 1]) that it labels Adélie. This tree is smaller (5 leaves vs. 6) and has a training accuracy of about 96.1% (9 mistakes in 233).

III. Tree 3: Gini, No Maximum Depth

For this tree no maximum depth was specified, so it was not limited to a fixed number of levels, and only the minimum leaf size of 5 penguins keeps it from growing further. Its top three levels are identical to Tree 1, but the mixed leaf of 10 penguins ([4, 5, 1]) is now split again on culmen length (≤ 47.2 mm) into two leaves of 5 penguins: [4 Adélie, 1 Chinstrap] and [0 Adélie, 4 Chinstrap, 1 Gentoo]. This reduces the training mistakes from 10 to 7, raising the training accuracy to about 97.0%.

  • Flipper length is the most important feature. All three trees use it as the first split, and it nearly isolates the Gentoo species on its own.
  • Gini and entropy gave very similar trees. With the same depth limit, they chose the same root split and the same Gentoo branch and differed only in how the Adélie/Chinstrap side was divided, which matches the idea that the choice of criterion matters little in practice.
  • Adélie and Chinstrap are the harder pair to separate. Every impure leaf in every tree contains these two species, so the remaining errors come from penguins whose measurements overlap.
  • On the Testing Set, the two Gini trees were best and tied at 98.0% (99 of 101 correct), and the entropy tree reached 95.0% (96 of 101). The entropy tree made five mistakes against two for the Gini trees, but with only 101 test penguins a gap of three penguins is small, so we should not conclude that Gini is better than entropy in general.
  • Gini and Gini with no maximum depth tied because the extra split almost never comes into play. The only difference between Trees 1 and 3 is the extra split of a 10-penguin leaf, and only 2 of the 101 test penguins (both Chinstrap) reach that leaf. Both trees label them correctly, so the predictions on the Testing Set are identical, and both trees make the same two mistakes: Chinstrap penguins with small bodies (flipper length 187 mm) that land in the Adélie branch.
  • Fitting the training data better did not improve the test results. Tree 3 has the highest training accuracy (97.0%), but that gain did not carry over to new penguins. Training accuracy always rises as a tree grows, so the Testing Set is what shows how well each tree generalizes.

Conclusion

Decision trees predicted penguin species very accurately from four body measurements: the best trees classified 99 of the 101 penguins in the Testing Set correctly (98.0%), and the weakest still reached 95.0%. The species differ enough in size and shape that a few simple threshold questions are enough to tell them apart, and the tree shows exactly which questions those are.

The trees also show which measurements matter. Every tree starts with flipper length (≤ 206.5 mm), which nearly isolates Gentoo penguins on its own, and then uses culmen length and body mass to separate Adélie from Chinstrap. Adélie and Chinstrap are the hard pair: every remaining mistake involves them, and in the test set both errors made by the best trees were small-bodied Chinstrap penguins labeled Adélie. This agrees with the Naive Bayes results, where Chinstrap was also the species the model found hardest.

The choice of criterion mattered little. Gini and entropy picked the same first split and the same Gentoo branch, and differed only in how the Adélie/Chinstrap side was divided. Removing the depth limit also made no difference on the Testing Set, because the extra split affected only a handful of Chinstrap penguins. In practice, the more important choice is how much to restrict a tree: a minimum leaf size of 5 and a modest depth keep the tree small and readable without costing accuracy here.

What we can predict: for a new penguin from the same population, we can estimate its species from its measurements with roughly 95–98% accuracy, and we can explain each prediction as a short sequence of if/then rules. The limits are that the Testing Set has only 101 penguins, so one penguin shifts the accuracy by about one percentage point and the differences between our trees are within that noise, and that a single random split was used, so a different split could rank the trees differently. These results also describe species identification from body measurements, not trends in colony size or climate.
