NAIVE BAYES

Overview

1. What Is Naive Bayes?

Naive Bayes (NB) is a supervised machine learning method used for classification. It is trained on labeled examples and then predicts the class of a new observation. It is built on Bayes' theorem, which gives the probability of each class given the observed features: P(class | features) ∝ P(class) × P(feature1 | class) × P(feature2 | class) × … The model predicts the class with the highest result.

What makes the method "naive" is its assumption that features are conditionally independent given the class: once the class is known, the value of one feature is assumed to tell us nothing extra about another. This is rarely exactly true, but it keeps the model simple. Every feature contributes evidence to the prediction, and the probabilities for each feature can be estimated separately. NB is therefore fast to train, works reasonably well with small datasets, and is often used as a strong baseline.

2. What Is Naive Bayes Used For?

NB is used for classification tasks, particularly where there are many features and limited training data. Common applications include spam filtering, document and topic categorization, sentiment analysis, and building quick baseline classifiers to compare against more complex models.

3. Types of Naive Bayes

The variants differ in how they model P(feature | class), which depends on the type of feature in the data.

Multinomial Naive Bayes models features as counts, such as how many times each word appears in a document. For each class it learns how frequently each feature occurs, then classifies a new observation by asking which class's frequency pattern it resembles most. For example, a message with many occurrences of words like "free" and "winner" looks more like past spam than past non-spam. It is the standard choice for text classification and for any data made up of non-negative counts.

Bernoulli Naive Bayes models features as binary values: each feature is either present (1) or absent (0), regardless of how many times it occurs. In text, this means only whether a word appears in a document, not how often. Unlike multinomial NB, it also treats the absence of a feature as evidence for or against a class. It suits short texts and data that are naturally yes/no.

Gaussian Naive Bayes models continuous features by assuming that, within each class, each feature follows a normal distribution. For example, in the penguin data it would assume body mass is normally distributed separately for each species, using that class's own mean and standard deviation.

Data Preparation for Naive Bayes

1. Data Requirements for Supervised Learning

Naive Bayes is a supervised method, so it can only learn from labeled data: every observation must come with the correct answer (the class label) that the model is trying to predict. The model learns how the features are distributed within each class, and it can only do that if it knows which class each example belongs to. Unlabeled observations cannot be used to train or to evaluate a supervised model, because there would be nothing to compare the predictions against.

The data must also be in a numeric, complete form that the chosen Naive Bayes variant can use (for example, continuous measurements for Gaussian NB, or non-negative counts for multinomial NB), with no missing values.

2. Preparing the Penguin Data

For Naive Bayes we use the Palmer Penguins size measurements, where each row is one individual penguin. The label is the penguin's species (Adélie, Chinstrap, or Gentoo), and the model uses physical measurements as features: culmen (bill) length and flipper length. Species is a known, recorded label for every penguin, which makes this dataset suitable for supervised learning. The goal is to predict a penguin's species from its measurements alone.

The raw file contains 344 penguins. Rows with missing values (10 penguins) were removed, leaving 334 labeled observations. A sample of the cleaned data is shown below.

3. Creating the Training and Testing Sets

To find out how well a model works on penguins it has not seen, the labeled data was randomly split into two parts: a Training Set (about 70%) used to build the model, and a Testing Set (about 30%) held back to measure its accuracy. For the testing set, the model is given only the features, makes a prediction, and that prediction is then compared with the true species label.

The two sets must be disjoint, meaning no penguin appears in both. If the testing data were also used in training, the model would have already seen those examples, so it could appear accurate simply by memorizing them. The accuracy would then say little about how it performs on new penguins. Keeping the sets separate means the test accuracy is an honest estimate of how the model will generalize.

Results

I. Confusion Matrix

The confusion matrix summarizes how the Naive Bayes model performed on the 101 penguins in the testing set, which it never saw during training. Each row is the true species and each column is the predicted species (labels 0, 1, and 2 correspond to Adélie, Chinstrap, and Gentoo). The diagonal shows correct predictions and every off-diagonal cell is a mistake.

II. Performance

The model correctly classified 98 of 101 test penguins, an overall accuracy of about 97%. Per class:

  • Class 0 (Adélie): all 49 were identified correctly (recall 100%). Of the 51 penguins predicted as class 0, 49 were correct (precision 96%), because two penguins from class 1 were wrongly labeled as class 0.
  • Class 1 (Chinstrap): 15 of 18 were identified correctly (recall 83%). Every penguin predicted as class 1 really was class 1 (precision 100%), but the model missed three of them: two were predicted as class 0 and one as class 2.
  • Class 2 (Gentoo): all 34 were identified correctly (recall 100%). Of the 35 penguins predicted as class 2, 34 were correct (precision 97%).

III. Interpretation

All three errors came from class 1, so the model's weakness is specific to that species and is not spread across the data. Two things likely contribute. Class 1 is the smallest group (18 of 101 test penguins, and the fewest training examples), so the model has less data to learn its feature distributions and a lower prior probability for it. Its measurements may also overlap with those of the other species, and a penguin near the boundary between two classes is the one the model is most likely to get wrong. Since Naive Bayes also assumes the features are independent given the species, and culmen length and flipper length are likely to be correlated, the probabilities it computes near those boundaries will not be perfectly calibrated.

Overall, even with its simple independence assumption, Naive Bayes separated the three species very well using only two measurements. With only 101 test points, a single penguin changes the accuracy by about one percentage point, so the exact figures should be read as an estimate rather than a precise measure.

Conclusion

Using only two body measurements, culmen length and flipper length, a Naive Bayes model identified penguin species correctly for about 97% of the penguins in the testing set (98 of 101). This tells us that the three species differ enough in size and shape that their physical measurements are a strong signal of which species an individual is, even under the simplifying assumption that the features are independent of each other.

The model is not equally good at every species. Adélie and Gentoo were identified perfectly, while all of the mistakes came from Chinstrap penguins, three of the 18 in the testing set. Chinstrap is the smallest group in the data and appears to overlap the others in its measurements, so it is the species we would expect to be most confused with the others, and the one where a prediction deserves the least trust.

What this lets us predict: given the culmen length and flipper length of a new penguin from the same population, we can predict its species with high confidence, which is useful when a species cannot be observed directly. Because the model produces probabilities, it can also flag uncertain cases, such as individuals near the boundary between two species, for a closer look.

There are limits to what we can conclude. The testing set has only 101 penguins, so the accuracy is an estimate and could shift by about a point for every penguin that is classified differently. The data also comes from one set of measurements, so we cannot say how well the model would perform on penguins from other colonies or years. Finally, this model predicts species from body measurements. It does not by itself tell us anything about how colony sizes or the climate are changing, which the clustering and other sections of this project address.
