ADABOOST

Overview

1. What Is Boosting?

Boosting is an ensemble method that combines many simple, weak models into one strong model. A weak learner is a model that is only slightly better than random guessing. Boosting builds the learners one after another, and each new learner is trained to focus on the observations that the earlier learners got wrong. The final prediction combines all of them, so the mistakes of any single learner are corrected by the others.

2. Boosting vs. Bagging

Bagging (as in random forests) and boosting are both ensembles of trees, but they work in opposite ways:

  • Bagging builds trees independently and in parallel. Each tree is trained on a random bootstrap sample of the data, and the trees vote equally. It mainly reduces variance (overfitting) by averaging many deep, flexible trees.
  • Boosting builds trees sequentially. Each tree depends on the ones before it, because the data is reweighted to emphasize earlier mistakes, and the trees do not vote equally. It mainly reduces bias by combining many shallow, simple trees.

3. Decision Stumps

The weak learner AdaBoost most often uses is a decision stump: a decision tree with a single split (depth 1). A stump asks just one question about one feature, such as "is flipper length < 206.5 mm?", and predicts a class on each side. One stump is a weak classifier, since it can only draw one straight boundary along one feature, but it is fast to train and, being better than chance, it is enough for boosting to build on.

4. How AdaBoost Works

AdaBoost (Adaptive Boosting) starts by giving each of the N training rows the same weight, wi = 1/N. Then, for each round t = 1, 2, …, T:

  1. Fit a stump to the training data, using the current row weights. The split is chosen to minimize the weighted error, so heavy rows count more.
  2. Compute the stump's weighted error εt: the sum of the weights of the rows it misclassified.
  3. Compute the stump's weight αt (explained below).
  4. Reweight the rows: increase the weights of the misclassified rows and decrease the weights of the correctly classified ones, then normalize so the weights sum to 1.

The next stump therefore sees a version of the problem where the rows that were hard so far matter most, and it is forced to pay attention to them. For two classes coded as −1 and +1, the update is:

wi ← wi × e−αt yi ht(xi)

where yi ht(xi) is +1 when the stump is right and −1 when it is wrong. A correct row is multiplied by e−α (smaller than 1) and a wrong row by eα (larger than 1).

5. The Stump Weight α

Not every stump deserves the same say in the final answer. The weight, or "amount of say," of stump t is:

αt = ½ ln((1 − εt) / εt)

  • If the stump is very accurate (ε close to 0), α is large and positive, so it gets a big say.
  • If the stump is no better than guessing (ε = 0.5), α = 0, so it gets no say.
  • If the stump is worse than guessing (ε > 0.5), α is negative, so its vote is flipped. (In practice this is avoided, since the stump can simply be inverted.)

α plays two roles: it sets how much that stump counts in the final vote, and it sets how aggressively the rows are reweighted after the stump. For example, ε = 0.2 gives α = ½ ln(4) ≈ 0.69, while ε = 0.4 gives α = ½ ln(1.5) ≈ 0.20.

6. The Final Weighted Vote

After T rounds, a new observation x is classified by letting every stump vote, with each vote multiplied by that stump's α. For two classes (−1 and +1):

H(x) = sign( α1h1(x) + α2h2(x) + … + αThT(x) )

The class with the larger total α across the stumps that voted for it wins. For more than two classes (such as the three penguin species), the same idea applies: the α of the stumps voting for each class is added up, and the class with the highest total is predicted. Because accurate stumps have large α, a few reliable stumps can outvote many weak ones, and the combination of many weak stumps can draw a boundary far more flexible than any single stump.

Data Preparation for AdaBoost

1. Data Requirements for Supervised Learning

AdaBoost is a supervised method, so it can only learn from labeled data: every observation must come with the correct class label. The algorithm re-weights each training row according to whether the current stump classified it correctly, which is only possible when the true label of every row is known. Unlabeled rows cannot be used to train or to evaluate the model.

AdaBoost in scikit-learn (AdaBoostClassifier) also needs numeric inputs with no missing values, so any categorical column must be converted to numbers first. Like a single decision tree, it does not need the numeric features to be scaled, because each stump is just a threshold on one feature.

2. Preparing the Penguin Data

We use the Palmer Penguins size data, where each row is one individual penguin. The label is the penguin's species (Adélie, Chinstrap, or Gentoo), and the features are sex and four measurements: culmen_length_mm, culmen_depth_mm, flipper_length_mm, and body_mass_g. The island column was left out of the features, because island and species overlap heavily, so island would reveal much of the answer.

The raw file has 344 penguins. Rows with missing values were dropped (dropna()), leaving 334. Checking the distinct values of the text columns showed one invalid entry, a sex value of "." instead of MALE or FEMALE, so that row was removed too, leaving 333 labeled penguins. 3. Turning Categorical Columns into Numbers

The four measurements are already numeric. The feature sex is text (MALE or FEMALE), and the model cannot use text, so it was converted with one-hot encoding (OneHotEncoder): each category becomes its own 0/1 column that is 1 when the penguin belongs to that category. This is safer than coding the categories as numbers such as 1 and 2, which would invent an order between them. The example below shows the idea:

Beforesex_FEMALEsex_MALE
sex = MALE 0 1
sex = FEMALE 1 0 
onehot_encoder = OneHotEncoder(sparse_output=False)
sex_encoded = onehot_encoder.fit_transform(penguin_size_cleaned[["sex"]])
sex_df = pd.DataFrame(sex_encoded,
                      columns=onehot_encoder.get_feature_names_out(["sex"]),
                      index=penguin_size_cleaned.index)

numeric_cols = ["culmen_length_mm", "culmen_depth_mm", "flipper_length_mm", "body_mass_g"]
X = pd.concat([penguin_size_cleaned[numeric_cols], sex_df], axis=1)
y = penguin_size_cleaned["species"]

The final feature table has six numeric columns: the four measurements plus sex_FEMALE and sex_MALE. Unlike the regression models, both sex columns are kept, because a stump can split on either one and there is no coefficient to make redundant. The target species does not need encoding, because scikit-learn accepts class names directly.

4. Creating the Training, Validation, and Testing Sets

AdaBoost has settings to tune (the number of stumps n_estimators and the learning_rate), so the data was split into three parts rather than two, using train_test_split twice with a fixed seed (random_state=42) so the split can be reproduced, and stratify so each part keeps the same share of each species:

  • First, 15% of the penguins were set aside as the final Testing Set (50 penguins). The other 85% (283 penguins) were kept for building the model.
  • Then that 85% was split into a Training Set of 233 penguins (about 70% of the total) and a Validation Set of 50 penguins (about 15%), using test_size = 0.15 / 0.85 ≈ 0.1765.
# Final test set (15%), then train (70%) and validation (15%) from the rest
X_temp, X_test, y_temp, y_test = train_test_split(
    X, y, test_size=0.15, stratify=y, random_state=42)
X_train, X_val, y_train, y_val = train_test_split(
    X_temp, y_temp, test_size=0.1765, stratify=y_temp, random_state=42)

The Training Set is used to fit the stumps, the Validation Set is used to compare settings, and the Testing Set is used once, at the end, to measure accuracy. The sets must be disjoint, meaning no penguin appears in more than one. AdaBoost keeps increasing the weight of the rows it gets wrong, so with enough rounds it can fit even unusual training rows, and if test penguins were in the training data the model could look accurate simply by having memorized them. Keeping the Testing Set untouched, and not using it to choose settings, makes the test accuracy an honest estimate of how the model will generalize.

Results

I. Tuning

AdaBoost with the default decision stump (AdaBoostClassifier) was fit on the 233-penguin Training Set for 20 combinations of learning_rate (0.01, 0.1, 0.5, 1.0) and n_estimators (10, 25, 50, 100, 200), and each was scored on the 50-penguin Validation Set. The five best were:

learning_raten_estimatorsTraining accuracyValidation accuracy
1.0 200 99.1% 100%
1.0 100 99.1% 100%
1.0 50 99.1% 100%
1.0 25 98.7% 100%
0.5 100 97.4% 98%

With learning_rate = 1.0, validation accuracy reached 100% by 25 rounds and stayed there, and lower learning rates improved more slowly. Since 50, 100, and 200 stumps performed the same, the simplest setting where both training and validation accuracy had leveled off was chosen: n_estimators = 50 and learning_rate = 1.0, which also needs less computing.

II. Test Results

The chosen model was refit on the training and validation penguins together (283 penguins) and then used once on the 50-penguin Testing Set. It reached 96% accuracy (48 of 50 correct), slightly below its 100% validation accuracy, which is expected with only about 50 penguins in each set.

III. Comparison with a Decision Tree

A single Gini decision tree, with the same settings as on the Decision Trees page, was fit on the same training and validation penguins and scored on the same Testing Set. It reached 92% accuracy (46 of 50).

ModelTest accuracyCorrectErrors
AdaBoost (50 stumps) 96% 48 of 50 2, both Adélie
Decision tree 92% 46 of 50 4, across all three species
  • AdaBoost beat the single tree (96% vs. 92%). The tree made errors in all three species: 1 Adélie as Chinstrap, 1 Chinstrap as Adélie, and 2 Gentoo as Chinstrap.
  • A likely reason is that the tree is one model limited to a shallow depth, while AdaBoost combines 50 stumps with a weighted vote. Because each round gives more weight to penguins that earlier stumps misclassified, later stumps focus on the hard cases near the species boundaries.
  • The gap is small. It is only 2 penguins on a 50-penguin test set, so AdaBoost's advantage is real but modest.

Conclusion

AdaBoost predicted penguin species from sex and four body measurements with 96% accuracy on the Testing Set (48 of 50 penguins). Tuning showed that the model needed few stumps: with a learning rate of 1.0, validation accuracy reached 100% by 25 rounds, so 50 stumps were enough.

AdaBoost made two mistakes, both Adélie penguins (one labeled Chinstrap and one Gentoo), and classified every Chinstrap and Gentoo correctly. Compared with a single depth-limited decision tree on the same data (92%), it made half as many errors, and the tree's mistakes were spread across all three species. This fits the idea behind boosting: by re-weighting the penguins that earlier stumps got wrong, later stumps concentrate on the hard cases near the species boundaries, and the weighted vote of many simple stumps is more accurate than one tree.

What we can predict: for a new penguin from the same population, we can estimate its species from its measurements with roughly 92–96% accuracy, and AdaBoost looks slightly better than a single tree. The limits are that the Testing Set has only 50 penguins, so each penguin shifts the accuracy by two percentage points and the 2-penguin gap between AdaBoost and the tree is within that noise, that a single random split was used, and that the validation accuracy of 100% was higher than the test accuracy, a reminder that tuning on a small validation set can be a little optimistic.
