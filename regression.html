REGRESSION

Overview

1. Two Kinds of Regression

Linear regression and logistic regression are both supervised models that combine the features into a single weighted sum, called the linear score: z = b0 + b1x1 + b2x2 + … + bpxp. The coefficients b are learned from labeled training data. What differs is what the model does with that score, and therefore what it predicts.

2. Linear Regression: Predicting a Number

Linear regression predicts a continuous numeric value, such as a penguin's body mass or a house's price. The prediction is the linear score itself: ŷ = z. Geometrically, with one feature the model is the straight line that best fits the data, and with several features it is a flat plane (or hyperplane). The coefficients are chosen to minimize the sum of squared errors between the predicted and true values, so each b tells us how much the prediction changes when that feature increases by one unit and the others stay fixed.

3. Logistic Regression: Predicting a Class

Logistic regression is a classification model. It predicts a category (for example, spam or not spam, or one penguin species versus another), and more precisely it predicts the probability that an observation belongs to a class. A linear score cannot be used directly for this, because z can be any number from −∞ to +∞, while a probability must lie between 0 and 1.

From a linear score to a probability: the sigmoid

Logistic regression fixes this by passing the score through the sigmoid (logistic) function:

p = σ(z) = 1 / (1 + e−z)

The sigmoid squashes any real number into the range (0, 1) with an S-shaped curve. A large positive score gives a probability near 1, a large negative score gives a probability near 0, and a score of exactly 0 gives p = 0.5. Equivalently, the linear score is the log-odds of the class: z = ln(p / (1 − p)), so each unit increase in a feature multiplies the odds by eb.

From a probability to a class

To make a final decision, the probability is compared with a threshold, usually 0.5: if p ≥ 0.5 the model predicts class 1, otherwise class 0. Because p = 0.5 exactly when z = 0, the boundary between the classes is where the linear score equals zero, which is a straight line (or plane) in feature space. The threshold can be moved: lowering it catches more positives at the cost of more false alarms. For more than two classes, the model either fits one logistic regression per class or uses the softmax function, and predicts the class with the highest probability.

The coefficients are learned by maximizing the likelihood of the training labels (equivalently, minimizing the log loss), rather than by least squares.

Data Preparation for Regression

1. Data Requirements for Supervised Learning

Both linear and logistic regression are supervised methods, so they can only learn from labeled data: every observation must come with the correct answer (the target) that the model is trying to predict. The coefficients are fit by comparing the model's predictions with the true targets, which is impossible for unlabeled rows. The two models need different kinds of target, and both need numeric features with no missing values:

  • Linear regression needs a numeric (continuous) target. We predict a penguin's body mass in grams (body_mass_g).
  • Logistic regression needs a two-class label. We predict a penguin's sex (sex: FEMALE or MALE), which has exactly two classes.

2. Preparing the Penguin Data

We use the Palmer Penguins size data, where each row is one individual penguin. The raw file has 344 penguins. Rows with missing values were dropped (dropna()), leaving 334. Checking the distinct values of the text columns then showed one invalid entry, a sex value of "." instead of MALE or FEMALE, so that row was removed too. The result is 333 labeled penguins (168 male and 165 female), which are used for both models so that they can be compared on the same penguins. A sample of the cleaned data is shown below.

The island column was left out of both models, because island and species overlap heavily (for example, nearly all Gentoo penguins live on Biscoe), so it adds little beyond species. The text columns that are used, species and sex, have to be turned into numbers first. The columns used by each model are:

Encoding the categorical columns

Regression multiplies each feature by a coefficient, so text must become numbers. One-hot encoding was used: each category becomes its own 0/1 column. With OneHotEncoder(drop="first") the first category is dropped (Adélie for species, FEMALE for sex), because it is already implied when all the other columns are 0. Dropping it also avoids perfectly redundant columns, which would make the linear model's coefficients unstable. The dropped category becomes the baseline against which the other coefficients are read. For logistic regression the target sex was label-encoded instead (LabelEncoder: FEMALE = 0, MALE = 1).

Scaling (logistic regression only)

For logistic regression the numeric features were standardized with StandardScaler (mean 0, standard deviation 1), so that features measured in very different units (grams versus millimeters) are on the same scale and the optimizer converges reliably. It also makes the coefficients comparable: each one describes the effect of a one-standard-deviation change. The scaler was fit on the Training Set only and then applied to the Testing Set, so that no information from the test penguins leaks into training. Linear regression was fit on the unscaled features, so that its coefficients stay in their natural units (grams per millimeter).

3. Creating the Training and Testing Sets

To find out how well each model works on penguins it has not seen, the 333 labeled penguins were randomly split with scikit-learn's train_test_split, using test_size=0.3 and random_state=42 (a fixed seed so the split can be reproduced): a Training Set of 233 penguins (about 70%) used to fit the coefficients, and a Testing Set of 100 penguins (about 30%) held back to measure performance. For logistic regression the split was also stratified by sex, so both sets keep the same share of males and females (the Testing Set has 50 of each). For the Testing Set, the model is given only the features, makes a prediction, and the prediction is compared with the true value (body mass for linear regression, sex for logistic regression).

The two sets must be disjoint, meaning no penguin appears in both. A regression fit adjusts its coefficients to the training rows, so if test penguins were also in the training data, the model would be graded on rows it had already used to learn, and its error would look better than it really is. Keeping the sets separate makes the test error (or test accuracy) an honest estimate of how the model will do on new penguins.

  • R² = 0.89: the model explains about 89% of the variation in penguin body mass.
  • RMSE = 254.5 g: the predictions are typically off by about 255 g. Always guessing the average mass would be off by roughly the standard deviation (779.8 g), so the model's error is about one-third of that baseline.

A logistic regression (LogisticRegression) was fit on the standardized Training Set (intercept 0.114) and used to predict sex for the 100 Testing Set penguins. Because the features were standardized, each odds ratio (ecoefficient) is the factor by which the odds of MALE are multiplied for a one-standard-deviation increase in that feature:

Flipper length gets almost no weight (odds ratio near 1) once body mass is in the model, because the two measurements are strongly correlated and carry much the same information.

III. Logistic Regression vs. Naive Bayes

A Gaussian Naive Bayes model fit on the same split reached only 77% accuracy (77 of 100), against 94% for logistic regression, about 17 more penguins wrong. Naive Bayes mislabeled 14 females as male and 9 males as female.

ModelTest accuracyFemale → male errorsMale → female errors
Logistic regression 94% 3 3
Naive Bayes 77% 14 9
  • Independence assumption. Naive Bayes treats the measurements as independent, but they are strongly correlated, so it counts the same "large penguin" evidence several times and distorts its probabilities. Logistic regression fits all the weights together, so it shares credit among correlated features.
  • Species differences. Naive Bayes models each measurement with one distribution per sex across all species, but species differ a lot in size, so a heavy female Gentoo can look "male" by Adélie standards. Logistic regression's species coefficients shift its boundary for each species, so it can separate the sexes within each species.

Conclusion

Regression worked well on both tasks. Linear regression predicted a penguin's body mass from its species, sex, and bill and flipper measurements with R² = 0.89 and a typical error of about 255 g, about one-third of the spread in body mass. Logistic regression predicted a penguin's sex from its measurements and species with 94% accuracy on the Testing Set.

The coefficients show why. In the linear model, species is the largest effect (Gentoo penguins are about 1 kg heavier than Adélie of similar size), followed by sex (males are about 390 g heavier), and each extra millimeter of culmen depth adds about 68 g. In the logistic model, culmen depth and body mass have the strongest effect on the odds of a penguin being male, while flipper length adds almost nothing once body mass is included because the two are so correlated.

The comparison with Naive Bayes shows why the logistic model's joint fit matters: logistic regression made 6 errors, while Naive Bayes made 23, because the independence assumption does not hold for correlated size measurements and because Naive Bayes ignores that the species differ greatly in size.

What we can predict: for a new penguin from the same population, we can estimate its body mass to within roughly 250 g, and tell its sex correctly about 94% of the time. The limits are that the Testing Set has only 100 penguins (so one penguin shifts the accuracy by one percentage point), that a single random split was used, that a straight-line model misses any curvature in the relationship (the largest and smallest penguins are slightly over- and under-predicted), and that these results describe penguins in this dataset, not other populations.
